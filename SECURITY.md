# Security policy

Report suspected vulnerabilities privately to **hello@husfund.app** with the affected
repository, impact, reproduction steps and a minimal non-sensitive example.
Do not include private keys, recovery notes, authentication tokens or user data.
Do not open a public issue for an exploitable vulnerability.

Do not test against funded Mainnet contracts or the production relayer without
explicit authorization. Use local isolated tests and mock funds. No response
SLA or bounty is promised by this policy.

Only the current default branch is maintained. A successful build or CI run
does not establish independent security certification.
